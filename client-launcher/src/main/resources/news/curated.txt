# The curated news channel's pool. One entry per line; blank lines and lines
# starting with # are skipped. No dates, no links: the rail draws these as plain
# lines and they open nowhere.
#
# <dataDir>/news-curated.txt replaces this file when it exists, and is re-read on
# every open, so the pool can grow without a rebuild.
#
# ── What makes a line land ──────────────────────────────────────────────────
#
# The mechanic is a magnitude that reads as a typo. Three shapes carry it:
#
#   a percentage with no base, because growth measured from something tiny is
#   always absurd and the absurdity is the arithmetic rather than the subject;
#
#   an inversion, where the thing that must be smaller is larger;
#
#   a collapsed distance, where two things nobody would put in one sentence turn
#   out to be neighbours.
#
# The failure mode is trivia. "Did you know an octopus has three hearts" is cosy,
# not absurd, and it does not survive being read twice.
#
# ── Two rules ───────────────────────────────────────────────────────────────
#
# The rail is SHAPED like a news feed, so a reader takes what is on it as fact.
# An invented number does not land as a joke, it lands as misinformation, and the
# joke was never the number: it is that the real one sounds invented. Verify what
# you write. A line that turns out to be wrong is not a line that was funny.
#
# Whatever goes here reaches everyone running the build, on the panel they opened
# to see whether their pack updated, not the one person it was aimed at.
#
# The pool below is a starting set. Roughly a magnitude more entries than the
# widget shows at once, so the draw does not repeat itself.
