# Хранение данных и Персистентность

> **Модуль:** `docs/ru/data-storage.md`
> **Контекст:** Локальная файловая структура, форматы JSON конфигурации и управление состоянием.

## 1. Обзор

Aura Launcher сохраняет все данные пользователя локально в формате **JSON**, используя библиотеку `kotlinx.serialization`. Приложение не использует локальные базы данных (SQLite/Realm), чтобы минимизировать накладные расходы и зависимости.

Корневая рабочая директория (`workDir`) определяется во время выполнения в зависимости от ОС (например, `%APPDATA%/AuraLauncher` в Windows или `~/.config/AuraLauncher` в Linux).

## 2. Конфигурационные файлы

### 2.1 Учетные данные (`credentials.json`)

**Менеджер:** `hivens.launcher.CredentialsManager`

Хранит активную сессию пользователя для реализации авто-входа.

* **Примечание о безопасности:** Пароль хранится в **Base64 кодировке**, а не в зашифрованном виде. Это обеспечивает обфускацию от случайного просмотра, но не является криптографически безопасным. Это решение принято для совместимости с легаси-лаунчерами.
* **Внутренняя структура (`SavedCredentials`):**
    * `username`: Игровое имя (IGN).
    * `accessToken`: Токен сессии от бэкенда.
    * `uuid`: Уникальный ID игрока.
    * `savedPasswordBase64`: Закодированная строка пароля.

```json
// Пример структуры
{
  "username": "Haru",
  "accessToken": "eyJhbG...",
  "uuid": "123e4567-e89b-...",
  "savedPasswordBase64": "cGFzc3dvcmQ="
}
```

### 2.2 Глобальные настройки (`settings.json`)

**Менеджер:** `hivens.launcher.SettingsService`

Сохраняет общесистемные предпочтения, определенные в `SettingsData`.

* **Ключевые поля:**
* `memoryMB`: Выделение RAM (По умолчанию: 4096).
* `seasonalTheme`: Переопределение визуальной темы (например, "WINTER", "AUTO").
* `closeAfterStart`: Флаг (Boolean) для закрытия лаунчера после старта игры.


* **Поведение:** Если файл отсутствует, создаются настройки по умолчанию.

### 2.3 Профили и Состояние (`profiles.json`)

**Менеджер:** `hivens.launcher.ProfileManager`

Хранит локальное состояние, специфичное для конкретного экземпляра клиента, отличное от данных сервера, полученных через API.

* **Формат (`ProfilesContainer`):**
* `lastServerId`: Идентификатор `assetDir` последнего выбранного сервера (для восстановления UI).
* `favorites`: Список ID серверов, отмеченных пользователем как избранные.
* `profiles`: Карта (Map) объектов `InstanceProfile`, содержащих переопределения для конкретных серверов (если есть).

## 3. Структура директорий

Лаунчер поддерживает строгую иерархию папок для игровых файлов, чтобы обеспечить изоляцию и целостность.

**Менеджер:** `hivens.launcher.util.ClientFileHelper`

```text
workDir/
├── credentials.json       # Данные авторизации
├── settings.json          # Глобальный конфиг
├── profiles.json          # Состояние UI и избранное
├── client/                # Корень игры (Рабочая папка)
│   ├── assets/            # Ассеты Minecraft (Объекты/Индексы)
│   ├── bin/               # Нативные файлы (.dll, .so) и библиотеки
│   ├── mods/              # Контент загрузчика модов
│   ├── resourcepacks/     # Ресурспаки пользователя
│   └── options.txt        # Настройки игры
└── updates/               # Временная папка для обновлений JRE/Лаунчера

```

### 3.1 Логика очистки

Для предотвращения накопления мусора (старых файлов модов), во время запуска вызывается `ClientFileHelper.cleanDirectory`.

* **Механизм:** Сканирует все файлы в `client/mods` или `client/bin`.
* **Фильтр:** Сравнивает с `FileManifest` (белый список).
* **Действие:** Удаляет любые `.jar`, `.zip`, `.dll` или `.so` файлы, которые явно не требуются манифестом сервера.

## 4. DTO против Моделей Домена

Важно различать типы данных, используемые при хранении, и те, что используются в UI:

| Тип                    | Слой               | Роль                                                       | Хранение             |
|------------------------|--------------------|------------------------------------------------------------|----------------------|
| **`SavedCredentials`** | Launcher (Private) | Минимальный DTO для хранения.                              | `credentials.json`   |
| **`SessionData`**      | Core (Public)      | Полный объект сессии для UI.                               | *Оперативная память* |
| **`ServerProfile`**    | Core (Model)       | Информация об удаленном сервере (IP, Имя).                 | *Загружается из API* |
| **`InstanceProfile`**  | Core (Data)        | Локальные настройки клиента (например, опциональные моды). | `profiles.json`      |
