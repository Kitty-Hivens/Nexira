## 🚀 Быстрый старт для контрибьюторов

1.  **Требования:**
    * JDK 21+
    * IntelliJ IDEA (рекомендуется)
    * Git

2.  **Сборка проекта:**
    ```bash
    # Запуск из корня проекта
    ./gradlew :client-ui:packageDistribution
    ```

3.  **Стиль кода:**
    * Следуйте стандартным конвенциям Kotlin.
    * Используйте `koinInject()` только в Composable верхнего уровня или Контроллерах.
    * Не помещайте бизнес-логику в UI-компоненты; используйте Контроллеры.
