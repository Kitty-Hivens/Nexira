# UI и Движок тем

> **Модуль:** `docs/ru/ui-theming.md`
> **Контекст:** Детали реализации визуального слоя, логика сезонной адаптации и кастомные компоненты рендеринга.

## 1. Стек технологий

Интерфейс Aura Launcher полностью построен на **Compose Multiplatform (Desktop)**. Проект отказывается от устаревших компонентов Swing/JavaFX в пользу современного, декларативного подхода к UI.

* **Рендеринг:** Skia (через Compose).
* **Управление окнами:** `androidx.compose.ui.window` (Безрамочное, Прозрачное).
* **Управление состоянием:** `mutableStateOf` / `remember` (Локальное), `StateFlow` (Глобальное через Контроллеры).

## 2. Система сезонных тем

Aura реализует динамический «Движок Атмосферы» (Atmosphere Engine), который адаптирует визуальное настроение приложения на основе реального календаря. Эта логика отвязана от слоя рендеринга и находится в `client-core`.

### 2.1 Логика (`SeasonTheme`)

**Источник:** `hivens.core.data.SeasonTheme`

Тема определяется методом `SeasonTheme.getCurrentSeasonalTheme()`, который проверяет системную дату:

| Enum Темы  | Период срабатывания | Визуальный замысел                                 |
|:-----------|:--------------------|:---------------------------------------------------|
| `NEW_YEAR` | 20 Дек – 14 Янв     | Интенсивный снег, праздничная атмосфера.           |
| `WINTER`   | 1 Дек – 28 Фев      | Спокойный снегопад, холодная палитра.              |
| `SPRING`   | 1 Мар – 31 Май      | Лепестки сакуры (Розовые), легкий бриз.            |
| `SUMMER`   | 1 Июн – 31 Авг      | Светлячки (Желтое/Зеленое свечение), ночные вайбы. |
| `AUTUMN`   | 1 Сен – 30 Ноя      | Листопад (Оранжевый/Коричневый), эффекты ветра.    |
| `NONE`     | (Фоллбэк)           | Статичный фон, без частиц.                         |

### 2.2 Пользовательское переопределение

Пользователь может переопределить автоматическое определение через Настройки. Это предпочтение сохраняется в `SettingsData` и внедряется в UI через `ISettingsService`.

## 3. Пайплайн рендеринга (`CelestiaBackground`)

Фон — это не статичное изображение. Это процедурно генерируемый холст (Canvas), который комбинирует радиальные градиенты со слоем симуляции частиц.

**Источник:** `hivens.ui.Main.kt`

### 3.1 «Дышащий» фон

Aura использует бесконечный цикл анимации для модификации координат фоновых градиентов, создавая эффект «живого» фона.

```kotlin
val t by infiniteTransition.animateFloat(...)
val x1 = width * 0.5f + cos(t) * width * 0.3f
val y1 = height * 0.5f + sin(t) * height * 0.2f

```

* **Математика:** Использует функции `sin` и `cos` для вращения центров градиентов вокруг центра окна.
* **Цвета:** Производные от `CelestiaTheme.colors.primary` и `success` с низкой альфой (0.05f - 0.15f) для обеспечения читаемости текста.

### 3.2 Система частиц (`SeasonalEffectsLayer`)

**Источник:** `hivens.ui.components.Particle.kt`

Кастомный легковесный движок частиц работает поверх фона.

* **Состояние:** Частицы хранятся в `SnapshotStateList`.
* **Цикл обновления:** `LaunchedEffect` с `withFrameNanos` триггерит обновление физики каждый кадр.
* **Поведение:**
* *Снег:* Движется вниз (`y + speed`), слегка покачивается по X (`sin`). Респавнится сверху.
* *Светлячки:* Движутся медленно в случайных направлениях, прозрачность пульсирует (`alpha` анимация).
* *Сакура:* Движется вниз-вправо (`x + wind`, `y + gravity`), вращается.

## 4. Архитектура компонентов

UI следует дизайн-языку «Глассморфизм» (Glassmorphism), реализованному через кастомные composables.

### 4.1 GlassCard

Компонент-контейнер, имитирующий матовое стекло.

* **Визуал:** Полупрозрачная поверхность (`Surface` с альфой), закругленные углы (`RoundedCornerShape`) и тонкая граница.
* **Использование:** Используется для Сайдбара, Списка серверов и панелей Настроек, чтобы анимированный фон просвечивал сквозь них.

### 4.2 Навигация (`AppState`)

Приложение использует простую State Machine (Конечный автомат) для навигации, избегая сложных библиотек маршрутизации.

**Состояния:**

1. **`Splash`**: Начальная загрузка (Проверка ассетов, Авто-вход).
2. **`Login`**: Ввод учетных данных (если сессия невалидна).
3. **`Shell`**: Основной контейнер для авторизованных пользователей.

**Навигация в Shell:**
Внутри `Shell` вторичная навигация переключает экраны контента (`Home`, `Profile`, `Settings`), оставляя Сайдбар статичным.

## 5. Палитра темы (`CelestiaTheme`)

**Источник:** `hivens.ui.theme.CelestiaTheme.kt`

Приложение определяет собственную систему цветов `CelestiaColors` вместо использования стандартных `Colors` из Material.

* **Primary:** Основной брендовый цвет (Фиолетовый/Синий).
* **Background:** Глубокий темный цвет (почти черный) для контраста.
* **Surface:** Немного светлее для карточек.
* **Text:** Вариации высокой (Primary) и средней (Secondary) важности.

Composable `CelestiaTheme` предоставляет эти цвета через `LocalCelestiaColors` (CompositionLocal), делая их доступными в любом месте дерева UI.
