---
title: Политика подписи кода
description: Какие файлы Nexira для Windows подписаны, что Windows делает с неподписанными и что лаунчер передаёт по сети.
---

Сборки Nexira для Windows пока не подписаны сертификатом проекта. Windows показывает лаунчер как программу неизвестного издателя, а на системе с включённым Smart App Control блокирует его сразу. Исключения для одного приложения у Smart App Control нет: обойти его можно, только выключив для всей системы.

## Что подписано

- **Среда Java внутри лаунчера.** Её файлы несут подписи, которые им дала BellSoft. Сборка берёт подписанные копии BellSoft вместо неподписанных, из которых собирается среда.
- **Java, на которой работает игра**, скачивается у BellSoft уже подписанной. Если BellSoft недоступна, она берётся у Adoptium в том виде, в каком её выпускает Adoptium.

## Что не подписано

- `Nexira.exe` и установщик (`Nexira-*-Setup.exe`).
- Графическая библиотека, которой рисуется интерфейс, она распаковывается при первом запуске.
- Библиотеки декодирования видео (FFmpeg), на которых играют живые обои и видео, они распаковываются при первом использовании.
- Файлы, которые игра скачивает сама, например нативные библиотеки её загрузчика модов.

Библиотеки, собранные другими, сохраняют подпись (или её отсутствие) от своих авторов.

## Как делаются сборки

Каждый релиз для Windows собирается в GitHub Actions из исходного кода этого репозитория, по тегу, с которого выпущен релиз. Скрипты сборки и workflow, который её делает ([`build_release.yml`](https://github.com/Kitty-Hivens/Nexira/blob/stable/.github/workflows/build_release.yml)), входят в этот исходный код. Ничего, собранного на машине разработчика, не публикуется.

Ночные сборки собираются из ветки разработки каждую ночь и предназначены для тестеров.

Nexira поддерживает один человек. Изменения от других людей приходят пулл-реквестами и проходят ревью до слияния.

## Приватность

Nexira не собирает телеметрию, не отправляет аналитику и не выгружает отчёты о сбоях. Отчёты о сбоях и логи остаются на твоём компьютере, пока ты сам не решишь ими поделиться.

Лаунчер обращается к другим системам только для того, что ты с ним делаешь:

- **GitHub**, чтобы проверить обновления лаунчера и прочитать их описание, найти выпуски загрузчиков Cleanroom и lwjgl3ify, а на Android скачать Java и графические библиотеки для телефона.
- **Сервисы контента, в который ты играешь**: Mojang и Microsoft для самой игры, твой аккаунт SMARTYcraft при входе, SMARTYcraft и его зеркало для сборок SMARTYcraft, Modrinth, когда ты ищешь или ставишь что-то оттуда, и репозитории загрузчиков модов, которые использует сборка.
- **BellSoft**, чтобы скачать среду Java, нужную игре.
- **Источники новостей**, которые показаны на главном экране.
- **Сервер картинок YouTube**, ради превью видео, встроенного в описание.
- **Видеосайты по ссылкам**, когда ты включаешь видео или ставишь его фоном по адресу: лаунчер забирает его через yt-dlp, а сам yt-dlp при первом использовании скачивает с GitHub.

У каждого из этих сервисов своя политика конфиденциальности, она действует на то, что ты там делаешь.
