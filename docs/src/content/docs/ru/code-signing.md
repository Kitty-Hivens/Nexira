Бесплатную подпись кода предоставляет [SignPath.io](https://about.signpath.io), сертификат выдан [SignPath Foundation](https://signpath.org).

## Что подписывается

Установщик для Windows (`Nexira-*-Setup.exe`) и исполняемый файл лаунчера внутри установщика и портативного архива, для каждого стабильного и бета-релиза на [GitHub Releases](https://github.com/Kitty-Hivens/Nexira/releases).

Каждый подписанный файл собирается в GitHub Actions из исходного кода этого репозитория, по тегу, с которого выпущен релиз. Скрипты сборки и workflow, который её делает ([`build_release.yml`](https://github.com/Kitty-Hivens/Nexira/blob/stable/.github/workflows/build_release.yml)), входят в этот исходный код. Ничего, собранного на машине разработчика, не подписывается.

Ночные сборки не подписываются. Они собираются из ветки разработки каждую ночь и предназначены для тестеров.

Библиотеки, которые Nexira поставляет в собранном другими виде, сохраняют подпись (или её отсутствие) от своих авторов.

## Роли в команде

Nexira поддерживает один человек.

| Роль                | Участники                                                      |
|---------------------|----------------------------------------------------------------|
| Коммиты и ревью     | [Сопровождающие Kitty-Hivens](https://github.com/Kitty-Hivens) |
| Утверждение подписи | [Сопровождающие Kitty-Hivens](https://github.com/Kitty-Hivens) |

Изменения от других людей приходят пулл-реквестами и проходят ревью до слияния. Каждый запрос на подпись утверждается вручную.

## Приватность

Nexira не собирает телеметрию, не отправляет аналитику и не выгружает отчёты о сбоях. Отчёты о сбоях и логи остаются на твоём компьютере, пока ты сам не решишь ими поделиться.

Лаунчер обращается к другим системам только для того, что ты с ним делаешь:

- **GitHub**, чтобы проверить обновления лаунчера и прочитать их описание.
- **Сервисы контента, в который ты играешь**: Mojang и Microsoft для самой игры, твой аккаунт Microsoft или SMARTYcraft при входе, SMARTYcraft и его зеркало для сборок SMARTYcraft, Modrinth, когда ты ищешь или ставишь что-то оттуда, и репозитории загрузчиков модов, которые использует сборка.
- **BellSoft**, чтобы скачать среду Java, нужную игре.
- **Источники новостей**, которые показаны на главном экране.

У каждого из этих сервисов своя политика конфиденциальности, она действует на то, что ты там делаешь.
