---
title: Установка
description: Как установить Nexira на Windows, Linux и macOS.
---

Скачай последний релиз с [GitHub Releases](https://github.com/Kitty-Hivens/Nexira/releases/latest).

## Windows

Релизы для Windows пока не подписаны. На системе с включённым Smart App Control Windows блокирует лаунчер, и обойти это можно, только выключив Smart App Control. Подробнее в [политике подписи кода](../code-signing/).

**Установщик (рекомендуется)**

1. Скачай `Nexira-*-Setup.exe`
2. Запусти -- права администратора не нужны
3. Лаунчер ставится в `%LocalAppData%\Nexira\Programs`

**Портативная версия**

1. Скачай `Nexira-*-Windows-Portable.zip`
2. Распакуй куда удобно
3. Запусти `Nexira.exe`

## Linux

1. Скачай `Nexira-x86_64.AppImage` (ночная сборка называется `Nexira-nightly-x86_64.AppImage`)
2. Сделай исполняемым и запусти:

```bash
chmod +x Nexira-x86_64.AppImage
./Nexira-x86_64.AppImage
```

Лаунчер обновляет этот файл на месте, поэтому имя и расположение от версии к версии не меняются. Ночная сборка в той же папке это отдельный файл: релиз её не перезапишет, и наоборот.

:::tip
В большинстве DE можно правый клик → Свойства → Разрешить выполнение как программы.
:::

:::note[Нужен FUSE]
AppImage требует FUSE. На Ubuntu 22.04+ может не быть из коробки:

```bash
sudo apt install libfuse2
```
:::

## macOS

1. Скачай `Nexira-*.dmg`
2. Открой DMG и перетащи приложение в Applications
3. При первом запуске правый клик → **Открыть**, если macOS заблокирует

:::note
**Apple Silicon** -- нативная сборка.  
**Intel** -- community-сборка (`Nexira-*-x86_64-community.dmg`); валидируется в CI, не входит в основной релиз-набор.
:::

## Android (бета)

1. Скачай `Nexira-*-Android-arm64.apk` на телефон
2. Открой его и разреши установку приложений из этого источника, когда Android спросит
3. Установи и открой Nexira

Нужен Android 12 или новее на телефоне с 64-битным ARM. На телефоне игра работает на LWJGL 3: Minecraft от 1.14 и новее, а также сборки 1.12.2 и 1.7.10 на Cleanroom или lwjgl3ify. Forge от 1.13 и NeoForge там пока не предлагаются.

## Первый запуск

1. Войди со своими данными SMARTYcraft
2. Выбери сервер
3. Жми **Играть** -- лаунчер синхронизирует файлы автоматически при первом запуске

### Переход с Aura

Если у тебя стояла Aura, Nexira увидит старую папку с данными при первом запуске и покажет обязательный экран миграции. Нажми **Перенести данные**, дождись окончания копирования и нажми **Закрыть Nexira**, потом запусти заново. Старая папка остаётся нетронутой как резервная копия; удали её вручную когда убедишься что всё работает.

## Где хранятся данные

| Платформа | Путь                                                           |
|-----------|----------------------------------------------------------------|
| Windows   | `%LOCALAPPDATA%\Nexira`                                        |
| macOS     | `~/Library/Application Support/Nexira`                         |
| Linux     | `$XDG_DATA_HOME/nexira` (по умолчанию `~/.local/share/nexira`) |

Папка установки -- отдельная: `%LocalAppData%\Nexira\Programs` (установщик Windows) или место AppImage на Linux. Пользовательские данные (клиенты, настройки, кэш скинов, краш-репорты, логи) живут по путям выше.

Для переопределения дефолта на любой платформе выстави переменную окружения `NEXIRA_DATA_DIR` в абсолютный путь до запуска. Альтернативно -- **Настройки → Расширенные → Каталог данных → Переместить...** покажет нативный пикер и применит перенос при следующем старте.
