## Где логи?

| | Путь |
|---|---|
| Отчёты о сбоях | `~/.aura/crash-reports/` (Linux/macOS) или `%AppData%\.aura\crash-reports` (Windows) |
| Вывод консоли | Иконка гаечного ключа в боковой панели → **Copy All** |

:::tip[Сообщаешь о баге?]
Всегда прикладывай отчёт о сбое или вывод консоли. [Открыть баг репорт →](https://github.com/Kitty-Hivens/Aura-Launcher/issues/new?template=bug_report.md)
:::

## Лаунчер не запускается

**Windows — падает до появления окна**

Убедись что используешь официальный установщик или portable ZIP со [страницы релизов](https://github.com/Kitty-Hivens/Aura-Launcher/releases/latest).

**Linux — AppImage не запускается**

Установи FUSE:

```bash
# Ubuntu/Debian
sudo apt install libfuse2

# Arch
sudo pacman -S fuse2
```

**Linux — пустое окно или краш на Wayland**

Попробуй принудительный XWayland:

```bash
_JAVA_AWT_WM_NONREPARENTING=1 ./AuraLauncher-*.AppImage
```

## Проблемы с входом

**Предупреждение об SSL-сертификате**

SSL-сертификат сервера мог истечь. Лаунчер покажет предупреждение — можно выбрать "Подключиться всё равно". Твои данные не передаются третьим лицам.

**"Bad login" или "User not found"**

Проверь данные на [smartycraft.ru](https://www.smartycraft.ru). Лаунчер использует тот же логин что и сайт.

## Игра не запускается

**Файлы перекачиваются каждый раз**

Это нормально при первом запуске или после обновления сервера. Лаунчер проверяет целостность файлов перед каждой сессией.

**Игра падает сразу**

Открой консоль (иконка гаечного ключа → Copy All) и посмотри Java ошибки. Частые причины:
- Мало RAM — увеличь в настройках сервера
- Конфликтующий опциональный мод — отключай моды по одному в настройках сервера

## Офлайн-режим

Включи **Офлайн-режим** в Настройки → Поведение чтобы пропустить авторизацию и синхронизацию.

:::caution
Офлайн-режим требует хотя бы одного предыдущего онлайн-запуска на том же сервере.
:::
