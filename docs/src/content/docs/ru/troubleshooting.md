## Где логи?

| | Путь |
|---|---|
| Краш-репорты | `<папка данных>/crash-reports/` |
| Логи сессии | `<папка данных>/logs/launcher.log` |
| Вывод консоли | Иконка гаечного ключа в боковой панели → **Copy All** |

`<папка данных>` -- это `%LOCALAPPDATA%\Nexira` (Windows), `~/Library/Application Support/Nexira` (macOS) или `$XDG_DATA_HOME/nexira` (Linux). Полная таблица в разделе [Установка](/Nexira/ru/installation/).

:::tip[Сообщаешь о баге?]
**Настройки → Диагностика → Создать diagnostic bundle** упакует обезличенные логи, краш-репорты, action ring и инфо о системе в один ZIP. Кнопка **Отправить на GitHub** рядом скопирует путь к ZIP в буфер и откроет преднастроенную форму issue. [Открыть баг репорт напрямую →](https://github.com/Kitty-Hivens/Nexira/issues/new?template=bug_report.md)
:::

## Лаунчер не запускается

**Windows -- падает до появления окна**

Убедись что используешь официальный установщик или portable ZIP со [страницы релизов](https://github.com/Kitty-Hivens/Nexira/releases/latest). Реальный стек краша смотри в `%LOCALAPPDATA%\Nexira\logs\launcher.log`.

**Linux -- AppImage не запускается**

Установи FUSE:

```bash
# Ubuntu/Debian
sudo apt install libfuse2

# Arch
sudo pacman -S fuse2
```

**Linux -- пустое окно или краш на Wayland**

Nexira идёт с Liberica JDK который работает с Wayland через XWayland нативно; никаких env-vars обычно не нужно. Если окно всё равно не появляется, проверь нативные зависимости Skiko:

```bash
# Arch
sudo pacman -S fontconfig freetype2 libglvnd

# Debian/Ubuntu
sudo apt install libfontconfig1 libfreetype6 libgl1
```

## Проблемы с входом

**Предупреждение об SSL-сертификате**

Сертификат API SMARTYcraft периодически истекает раньше чем оператор его продляет. Nexira показывает диалог SSL-обхода с тремя длительностями:

- **1 час** -- короткий простой, ждём что сегодня починят
- **30 дней** -- типичный цикл продления сертификата
- **Навсегда (100 лет)** -- если ты сдался относительно гигиены TLS у апстрима

Выданные обходы видны в **Настройки → Сеть → SSL bypasses** и отзываются в любой момент. Учётные данные по-прежнему уходят только в API SMARTYcraft, просто по соединению где сертификат не проверяется.

**"Bad login" или "User not found"**

Проверь данные на [smartycraft.ru](https://www.smartycraft.ru). Лаунчер использует тот же логин что и сайт.

**Аккаунты с 2FA**

Двухфакторная аутентификация работает. При входе на такой аккаунт лаунчер спросит код и завершит вход.

Что про неё стоит знать: SMARTYcraft завершает предыдущую сессию при каждом входе, а лаунчеру нужно войти заново, чтобы выдать игре сессию, за которую он может ручаться. Поэтому запуск на аккаунте с двухфакторкой спрашивает свежий код, а запуск второй игры завершает сессию первой. Сам, без тебя, лаунчер на такой аккаунт не входит никогда -- ни при старте, ни фоновой синхронизацией, -- так что открытие лаунчера во время игры игру не тронет.

## Игра не запускается

**Файлы перекачиваются каждый раз**

Это нормально при первом запуске или после обновления сервера. Лаунчер проверяет целостность (MD5) перед каждой сессией.

**Игра падает сразу**

Открой консоль (иконка гаечного ключа → Copy All) и посмотри Java-ошибки. Частые причины:

- Мало RAM -- подними лимит в **Настройки сервера → ОЗУ**
- Конфликтующий опциональный мод -- отключай по одному в **Настройки сервера → Моды**

**Кастомные JVM-флаги ломают запуск**

**Конструктор JVM-аргументов** (Настройки → Расширенные → Запуск, дальше кнопка конструктора в настройках пака или сервера) позволяет ставить кастомные GC / JIT / CDS / JFR-флаги. Если конфигурация ломает запуск -- сбрось к дефолтам там же.

## Сетевые проблемы

**Лента новостей пустая / не загружается список серверов**

Ни новостям, ни списку серверов аккаунт не нужен, так что пустая лента на лаунчере, в который ты не входил, означает что не достучались до хоста. Nexira ходит к SMARTYcraft напрямую по HTTPS, и если этот хост недоступен из твоей сети, лента и список серверов останутся пустыми -- запасного маршрута нет. Обход -- VPN или системный прокси.

Если хост отвечает, но у него истёк сертификат, лаунчер спросит про это там, где наткнулся на отказ, а не только внутри формы входа. Одного согласия хватит, чтобы новости и список серверов вернулись.

**Странности с папкой данных**

Если перемещал папку через **Настройки → Расширенные → Папка данных**, перенос применяется при следующем старте. Bootstrap-конфиг в `~/.nexira.conf` хранит цель; если миграция застряла -- проверь этот файл.

## Офлайн-режим

Включи **Офлайн-режим** в Настройки → Внешний вид → Поведение чтобы пропустить авторизацию и синхронизацию.

:::caution
Офлайн-режим требует хотя бы одного предыдущего онлайн-запуска на том же сервере (лаунчер использует закэшированный манифест файлов).
:::
