## Features

<CardGrid stagger>
  <Card title="All platforms" icon="laptop">
    Windows, Linux and macOS, and Android in beta. Every game gets the Java it needs, downloaded and set up by the launcher.
  </Card>
  <Card title="Almost any pack" icon="puzzle">
    Minecraft from 1.7.10 to the newest, on Forge, NeoForge, Fabric, Quilt or Cleanroom. SMARTYcraft servers sync before every session, packs and mods install from Modrinth, and instances come over from other launchers.
  </Card>
  <Card title="Yours to arrange" icon="setting">
    The home screen is widgets you place and size, with themes, wallpapers, and modules that bring widgets of their own.
  </Card>
  <Card title="Auto-updates" icon="rocket">
    The launcher updates itself. SHA256 verified, scheduled on exit.
  </Card>
  <Card title="Open source" icon="open-book">
    GPL-3.0. Fork it, extend it, do whatever.
  </Card>
</CardGrid>
