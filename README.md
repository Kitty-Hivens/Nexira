An unofficial third-party launcher for [SMARTYcraft](https://www.smartycraft.ru).  
Works on Windows, Linux and macOS — no manual Java setup required.

> Not affiliated with or endorsed by SMARTYcraft.

---

## Installation

Download the latest release for your platform:

| Platform           | File                                  |
|--------------------|---------------------------------------|
| Windows            | `AuraLauncher-*-Setup.exe`            |
| Windows (portable) | `AuraLauncher-*-Windows-Portable.zip` |
| Linux              | `AuraLauncher-*-x86_64.AppImage`      |
| macOS              | `AuraLauncher-*.dmg`                  |

→ [Latest Release](https://github.com/Kitty-Hivens/Aura-Launcher/releases/latest)

### Linux

```bash

chmod +x AuraLauncher-*.AppImage
./AuraLauncher-*.AppImage
```

### Windows

Run the Setup EXE. No admin rights required — installs to `%AppData%\AuraLauncher`.

### macOS

Open the DMG and drag the app to Applications.  
Apple Silicon native. Intel Macs supported via Rosetta 2.

## Features

- All servers: 1.7.10, 1.12.2, 1.21.1
- Automatic file sync and updates
- Skin upload and preview
- Offline mode
- Custom themes and backgrounds
- Russian, English, German
