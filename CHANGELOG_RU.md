# Изменения

Список изменений Nexira на русском языке. Ведётся с версии 2.3.4-beta4;
полная история на английском в [CHANGELOG.md](./CHANGELOG.md).

## [2.3.4-beta5] - 2026-06-09

Релиз про профиль и обновления. Профиль пересобран вокруг живого
3D-рендера скина, вход переехал внутрь профиля и доступен без
авторизации. Новый менеджер обновлений добавляет каналы выпуска, откат на
более раннюю версию, установку ярлыка и — для разработчиков — сборку
лаунчера из исходников.

### Главное
- **Твой скин в 3D**. Вкладка «Аккаунт» в профиле теперь ведёт живым 3D-рендером скина, который можно вращать; нарисован с нуля, без зависимостей.
- **Вход из профиля**. Форма входа живёт в профиле и доступна без авторизации; тесный вход в правом рейле убран.
- **Менеджер обновлений с каналами**. Значок «i» у версии открывает менеджер: выбор канала (Release / Beta / Alpha, плюс Dev / Git — сборка из исходников), обновление или откат на недавнюю версию, установка ярлыка.
- **Фоновые проверки обновлений**. Экран «О лаунчере» сам проверяет обновления раз в несколько минут и подсвечивает версию по её каналу.
- **Повреждённый мир или серверный файл больше не роняет лаунчер**. Кривая длина в NBT раньше клала весь лаунчер при сканировании.

## [2.3.4-beta4] - 2026-06-07

Релиз про сборки SmartyCraft. Сборка, нацеленная на сервер SmartyCraft,
теперь подключается и заходит на сервер (включая скины других игроков),
и при этом ничего из клиента SmartyCraft не распространяется. Вдобавок:
офлайн-перезапуск установленной сборки, учёт зависимостей у опциональных
модов, консоль, которая больше не подвисает при потоке логов, и
исправления адаптивной памяти.

### Главное
- **Сборки SmartyCraft заходят на свои серверы**. Сборка из зеркала,
  нацеленная на сервер SmartyCraft, теперь подключается и заходит, а скины
  других игроков загружаются.
- **Офлайн-перезапуск**. Уже установленная сборка запускается без сети;
  повторный запуск не делает ни одного сетевого запроса.
- **Опциональные моды тянут зависимости**. Включение опционального мода
  включает нужные ему библиотеки, а переключение мода внутри взаимозаменяемой
  группы (например, просмотрщика рецептов) выключает другой.
- **Консоль успевает за игрой**. Поток логов при загрузке модов больше не
  подвешивает и не роняет окно лаунчера.
- **Адаптивная память видит реальную RAM**. Установленная сборка теперь
  правильно определяет объём ОЗУ машины, а адаптивный подбор работает под
  ZGC и Shenandoah.

### Добавлено
- Заход на SmartyCraft через агент: для сборки, привязанной к серверу
  SmartyCraft, лаунчер подключает `-javaagent` без зависимостей, который при
  загрузке классов перенаправляет authlib на SmartyCraft (вызовы join, session
  и profile, а также белый список доменов текстур) и подгружает неподписанные
  скины других игроков. Два переключателя в Настройки -> Smarty: "сетевой
  агент" (включён) и старая подмена authlib-библиотеки (выключена, оставлена
  как запасной вариант).
- Офлайн-перезапуск: метаданные версии и подходящий индекс ассетов берутся
  с диска, поэтому установленная сборка перезапускается без сетевых запросов;
  отсутствующий или изменённый файл всё равно скачивается отдельно.
- Учёт зависимостей при переключении опциональных модов: включение мода
  включает требуемые им библиотеки; моды одной роли остаются
  взаимоисключающими.
- Периодический сброс метрик профайлера: метрики сессии пишутся каждые
  30 секунд, поэтому жёсткий выход (вызов `Runtime.halt` модом, нативный
  краш) больше не теряет всю сессию.
- Списки изменений на русском и немецком (`CHANGELOG_RU.md`,
  `CHANGELOG_DE.md`), начиная с этого релиза.

### Изменено
- Игровая консоль полностью вынесена с UI-потока, от приёма до отрисовки,
  поэтому поток логов больше не блокирует и не роняет окно.
- Адаптивный подбор кучи определяет живой набор под ZGC и Shenandoah, а не
  только под G1 / Parallel / CMS / Serial.
- Перенаправление auth-хоста для сборки теперь зависит от происхождения
  сборки: перенаправляются только сборки SmartyCraft и зеркала; Modrinth,
  локальные и собственные сборки остаются на стандартных хостах.
- Патч скинов SmartyCraft пишет одну строку в лог, когда изменившийся
  `getTextures` больше нельзя пропатчить, вместо тихой потери скинов
  других игроков.

### Исправлено
- Адаптивная память читает реальный объём ОЗУ на установленной сборке
  (раньше на упакованной среде выполнения откатывалась к фиксированным
  16 ГБ и неверно подбирала кучу).
